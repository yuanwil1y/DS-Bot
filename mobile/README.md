# DeepSeek Bot mobile

The DeepSeek Bot app for iOS and Android. It controls the Bot team that runs on your computer; nothing runs on the phone. The design is in [docs/plans/2026-10-24-mobile-app.md](../docs/plans/2026-10-24-mobile-app.md).

MVP (branch `mobile-app-mvp`): connect with the DSH token link, Bot list, private chat with live streaming replies.

- `src/api` — typed client for `POST /api/bot`, auth strategies (`auth.ts`, token → `dsh-auth-*` cookie; an Authelia step can be added as another `AuthStrategy`), live feed over the Remote WebSocket `/api/remote.mux` (`dsBot/feed`) with backoff reconnect, and a pure chat reducer.
- `src/screens` — Connect, Bot list, Chat. `src/components` — Avatar, Header, minimal Markdown.
- Android: `fetch` follows the 303 and OkHttp's cookie jar keeps the HttpOnly cookie; `WebSocket` sends it too. Cleartext HTTP is allowed (testing).

## Run

Needs Node 22 or later. iOS needs Xcode on macOS; Android needs the Android SDK and an emulator or a device. Expo Go is not supported, because the app will use native modules.

```sh
npm ci
npm run ios          # build and open in the iOS Simulator
npm run android      # build and open in the Android emulator
npm run typecheck
npm run test:api     # API layer vs. local mock backend: sh ../dev/mobile/run-local.sh start
```

Standalone APK (JS bundled, no Metro):

```sh
npx expo prebuild -p android
cd android && ./gradlew assembleRelease --no-daemon --max-workers=2 -PreactNativeArchitectures=arm64-v8a
# android/app/build/outputs/apk/release/app-release.apk (signed with the debug key)
```

`ios/` and `android/` are generated by the build and are not committed.
